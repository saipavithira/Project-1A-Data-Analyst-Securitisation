# Project-1A-Data-Analyst-Securitisation
🚗 AUTO LOAN PORTFOLIO DASHBOARD (Power BI)

📌 Project Overview

This project is an Interactive Auto Loan Portfolio Dashboard developed using Microsoft Power BI. It provides business insights by analyzing loan performance, collections, delinquency (DPD) buckets, outstanding balances, and portfolio risk using securitisation banking data.

The dashboard is fully interactive with slicers, enabling dynamic analysis of the loan portfolio.

---

🛠️ Tools & Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Transformation
- Dashboard Design

---

✨ Dashboard Features

- 🚗 Total Loan Count KPI
- 💰 Beginning Outstanding Balance (BOP) KPI
- 📈 Collections Trend by Reporting Date
- 🍩 Loan Distribution by DPD Bucket
- 📊 Amount Overdue by DPD Bucket
- 🎛️ Interactive Reporting Period Slicer

---

📊 Key Insights

- Portfolio contains 500 total loans.
- Beginning Outstanding Balance: ₹6.19 bn
- Collections peaked during June 2024.
- 496 loans are classified into DPD buckets.
- 1–29 DPD has the highest overdue amount.
